# GLP-1 FAERS Safety Signal Analysis
## Research Question 

Do semaglutide and tirzepatide show different adverse-event reporting patterns in FDA FAERS data?

## Hypothesis

I expect both drugs to show strong gastrointestinal adverse-event signals, such as nausea and vomiting. However, their overall reporting patterns may differ because they were introduced at different times and may be used by different patient populations.

## Data

This project uses quarterly adverse-event reports from the FDA Adverse Event Reporting System (FAERS).

The main files used in this analysis are:

- DEMO: patient and report information
- DRUG: reported drugs
- REAC: reported adverse reactions
- OUTC: patient outcomesThis project uses quarterly adverse-event reports from the FDA Adverse Event Reporting System (FAERS).

## Limitations

## Limitations

FAERS is a spontaneous reporting system, so the data cannot be used to calculate the true incidence of an adverse event. A reporting signal also does not prove that a drug caused the event.
